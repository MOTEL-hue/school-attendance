# מערכת נוכחות טלפונית לבית ספר

אתר ניהול + שלוחה טלפונית (ימות המשיח, מודול API) לדיווח איחורים וחיסורים של תלמידות.
אתר מרכזי אחד שמשרת הרבה בתי ספר: כל בית ספר נרשם בעצמו, בעלי המערכת מאשרים, והנתונים של כל בית ספר מבודדים
(סינון אוטומטי בכל שאילתה, עם בדיקות שמוודאות שאין דליפה). בית הספר מביא רק את קו ימות המשיח שלו.

## מה המערכת עושה

- **דיווח בטלפון:** מחייגים לשלוחה, מקישים ת.ז. של התלמידה, בוחרים: איחור לבית ספר / איחור לשיעור / חיסור.
  השעה נרשמת אוטומטית (אפשר לבחור שעה אחרת). חיסור: היום / מחר / אתמול / כמה ימים, סיבה (מחלה / אישור / אחר).
  אפשר לדווח על כמה תלמידות באותה שיחה.
- **הקלטת שם:** בדיווח הראשון על תלמידה מקליטים את שמה, והוא מושמע בכל שיחה אחר כך.
- **זיהוי המתקשרת** (נבחר בהגדרות): כל אחת / רק טלפונים רשומים / טלפון רשום + קוד אישי.
  הורה יכול לדווח רק על הבת שלו/ה.
- **התראות:** כללים גמישים (סף איחורים או חיסורים, טווח זמן, חוזר בכל כפולה או פעם אחת). כשהסף נחצה:
  הודעה למתקשרת בשיחה הבאה אחרי הקשת ת.ז., הצגה במסך ההתראות באתר, צינתוק או שיחה קולית להורים.
- **הרשמה ואישור:** בית ספר נרשם בעצמו או שבעל המערכת יוצר אותו. עד האישור האתר והטלפון חסומים. בעל המערכת יכול להשעות, למחוק ולהיכנס לבית ספר לתמיכה.
- **אשף התקנה** של ארבעה צעדים, ומחיקה עצמית של כל הנתונים. תנאי שימוש ופרטיות (טיוטה לעורך דין).
- **אבטחה:** הגבלת ניסיונות כניסה והרשמה, קודים אישיים מוצפנים, כתובת טלפון סודית ייחודית לכל בית ספר (אפשר להחליף).
- **אתר ניהול:** תלמידות וכיתות (כולל ייבוא מאקסל ומעבר שנה), דיווח וצפייה ועריכה, דוחות להדפסה ולאקסל,
  תאריך עברי, חופשות, מערכת שעות, יומן פעולות, גיבוי, וקוד תמיכה זמני לצפייה בלבד.

## העוזר האישי

כפתור "💬 עוזר אישי" בכל עמוד באתר. מסביר ומדריך, בודק את המצב האמיתי (הגדרות, חיבור לימות המשיח, תקינות הנתונים),
עונה על שאלות כמו "מי איחרה הכי הרבה החודש", ומציע שינויים: הגדרות, כללי התראה, חופשות, שיעורים, כיתות והגדרת השלוחה.
**שום שינוי לא מתבצע בלי לחיצה על "אישור" בכרטיס ההצעה.** העוזר לא מוחק ולא משנה דיווחים.

- דורש מפתח API של Claude (console.anthropic.com), שמוזן בעמוד **הגדרות** ונשמר מוצפן. העלות על חשבון בעל המערכת.
- הסיסמאות, המפתחות והכתובת הסודית של הטלפון לא נשלחים לבינה המלאכותית. מספרי ת.ז. נשלחים מוסתרים, ושמות ומספרים מצטברים נשלחים ל-Anthropic כשהעוזר עונה על שאלות על הנתונים.
- ההנחיות והידע של העוזר נמצאים ב-`attendance/assistant_knowledge.md` וניתנים לעריכה.
- כניסת תמיכה (צפייה בלבד) לא רואה את העוזר.

## הרצה מקומית

```bash
pip install -r requirements.txt
cp .env.example .env     # ולערוך
python manage.py migrate
python manage.py setup_admin       # יוצר משתמש admin לפי ADMIN_PASSWORD
python manage.py runserver
python manage.py test attendance   # בדיקות
```

## התקנה והפעלה

- בעל המערכת: [docs/INSTALL.md](docs/INSTALL.md) (Neon חינמי, מניעת שינה, אישור בתי ספר, עלויות).
- בית ספר: [docs/SCHOOL_GUIDE.md](docs/SCHOOL_GUIDE.md).

## התקנה ב-Render (תמצית)

1. מעלים את התיקייה ל-repo, ב-Render: New → Blueprint, בוחרים `render.yaml`.
2. מגדירים `DATABASE_URL` (PostgreSQL, למשל Neon) ו-`ADMIN_PASSWORD`. את `SECRET_KEY` ו-`PHONE_SECRET` Render מייצר.
3. נכנסים ל-`/login/` עם המשתמש `admin`, ואז לעמוד **הגדרות**.

## חיבור לשלוחה בימות המשיח

בעמוד **הגדרות** מופיע ה-`ext.ini` המוכן עם הכתובת הסודית. שתי דרכים:

- ידנית: יוצרים שלוחה חדשה במערכת הקיימת, ומדביקים בתוכה את ה-`ext.ini`.
- אוטומטית: מזינים מספר מערכת וסיסמה ותיקיית שלוחה (למשל `/7`) ולוחצים "הגדרה אוטומטית"
  (משתמש ב-`UpdateExtension`, לא מוחק הגדרות אחרות).

הסיסמה נשמרת מוצפנת. מומלץ לבדוק קודם על שלוחה לא פעילה.

## הערות חשובות

- הפורמט של ה-`read` / `id_list_message` נבנה לפי התיעוד של ימות המשיח אך **טרם נבדק על קו אמיתי**.
  בבדיקה הראשונה כדאי לעבור על כל שלבי השיחה ולדווח אם משהו נשמע שונה.
- שיחה קולית להתראה (ולא רק צינתוק) דורשת **תבנית קמפיין** בימות המשיח, שמזהה שלה מוזן בהגדרות.
- הקלטות השמות נשמרות בתיקיית השלוחה בימות המשיח (`name_<ת.ז.>`), ולא בשרת.
- ימי הלימוד, החופשות והשיעורים מוגדרים בכל התקנה לפי הצורך, ללא קשר למשרד החינוך.
