# מדריך לבעל המערכת: הפעלה, עלויות וניהול

המערכת היא אתר מרכזי אחד שמשרת הרבה בתי ספר. אתם מפעילים אותו פעם אחת. כל בית ספר נרשם בעצמו ואתם מאשרים.
בתי הספר לא צריכים חשבונות ב-Render, GitHub או Neon.

## מי משלם על מה

| רכיב | עליכם | על בית הספר |
|---|---|---|
| אתר ב-Render | מסלול חינמי מספיק להתחלה | אין |
| מסד נתונים Neon | מסלול חינמי | אין |
| קו הטלפון, צינתוקים ושיחות | אין | חשבון ימות המשיח שלהם |
| עוזר אישי (רשות) | אין | מפתח Anthropic שלהם |

המחירים והמגבלות משתנים אצל הספקים, ולכן בדקו מדי פעם בעמודי התמחור שלהם.

## הפעלה ראשונה (פעם אחת)

### 1. מסד נתונים קבוע (Neon)
המסד החינמי של Render נמחק אחרי כשלושים יום, ולכן משתמשים ב-Neon:
1. https://neon.tech ← פותחים חשבון חינם ← Create project (אזור Frankfurt).
2. בעמוד הפרויקט: **Connect** ← מעתיקים את ה-Connection string (נראית כ-`postgresql://user:pass@host/db?sslmode=require`).
3. ב-Render, בשירות `school-attendance` ← **Environment** ← מעדכנים את `DATABASE_URL` לערך הזה ← Save.
4. האתר יעלה מחדש ויבנה את הטבלאות לבד.

### 2. משתני סביבה ב-Render
| שם | מה |
|---|---|
| `DATABASE_URL` | כתובת Neon |
| `ADMIN_PASSWORD` | סיסמה חזקה לכניסה שלכם (משתמש `admin`) |
| `SECRET_KEY` | מחרוזת אקראית ארוכה (נוצרת אוטומטית ב-Blueprint) |
| `OWNER_CONTACT` | פרטי הקשר שיופיעו בתנאי השימוש ובפרטיות |

**חשוב:** אל תחליפו את `SECRET_KEY` אחרי שהמערכת בשימוש. היא מצפינה סיסמאות של ימות המשיח ומפתחות של העוזר, והחלפה תמחק אותם.

### 3. מניעת שינה (חינם)
האתר החינמי ב-Render נרדם אחרי כ-15 דקות בלי פניות, ושיחה טלפונית ראשונה אחריה עלולה להיכשל. פתרון חינמי:
1. https://cron-job.org ← חשבון חינם ← Create cronjob.
2. כתובת: `https://<הכתובת-שלכם>.onrender.com/healthz`, כל 10 דקות.
3. **מומלץ להגביל לשעות פעילות** (למשל 6:30 עד 20:00 לפי שעון ישראל). בחשבון Render החינמי יש מכסה חודשית של כ-750 שעות הפעלה לכל השירותים החינמיים יחד, ושירות שער כל היום לבדו אוכל כ-720 שעות. אם יש לכם שירותים חינמיים נוספים, הגבלת השעות חיונית.
4. בשעות שבהן האתר ישן (לילה, שבת) דיווח טלפוני עלול להיכשל פעם ראשונה. אם זה לא מקובל, מסלול Starter בתשלום (כ-7$ לחודש) פותר את זה.

אל תשתמשו ב-GitHub Actions לפינג: המכסה החודשית החינמית לריפו פרטי נגמרת מהר.

## הפעלה יומיומית

- **בקשות הרשמה:** נכנסים ב-`/login/` עם `admin`, נפתח עמוד **בתי ספר** (`/platform/`). לוחצים אישור. אין התראת מייל אוטומטית, אז בדקו את העמוד מדי פעם.
- **יצירה ישירה:** כפתור "יצירת בית ספר". תוצג סיסמה זמנית פעם אחת: שלחו אותה לבית הספר.
- **תמיכה:** כפתור "כניסה" מכניס אתכם לבית הספר כמנהלים. בית הספר יכול גם להפיק קוד תמיכה זמני (צפייה בלבד).
- **השעיה:** חוסמת גם את האתר וגם את הטלפון של בית הספר.
- **מחיקה:** מוחקת את כל הנתונים. נדרש להקליד את שם בית הספר.

## אחריות ופרטיות

המערכת שומרת מידע על קטינות. עמודי `/terms/` ו-`/privacy/` הם **טיוטות בלבד**. לפני שימוש מסחרי יש להעביר אותם לעורך דין, כולל בדיקת חובות רישום והודעה לפי חוק הגנת הפרטיות. זו אחריות שלכם כמפעילים.
