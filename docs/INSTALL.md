# מדריך התקנה לבית ספר

המדריך מיועד למי שמתקין את המערכת לבית הספר שלו, על החשבונות שלו. אין צורך בידע בתכנות.
משך ההתקנה: כ-30 דקות. המחירים בטבלה נכונים למועד הכתיבה, ויש לבדוק בעמודי התמחור.

## עלויות

| רכיב | חינם | מומלץ לשימוש אמיתי |
|---|---|---|
| אתר ב-Render | נרדם אחרי כמה דקות ללא שימוש | מסלול Starter (כ-7$ לחודש) שלא נרדם |
| מסד נתונים Neon | מספיק לבית ספר | חינם |
| עוזר אישי (לא חובה) | מופעל רק אם מזינים מפתח | לפי שימוש, בדרך כלל אגורות |
| צינתוקים ושיחות | | יחידות בחשבון ימות המשיח |

**חשוב:** במסלול החינמי של Render האתר "נרדם", והשיחה הראשונה אחרי שינה עלולה להיכשל עם "אין מענה משרת API".
לבדיקות זה בסדר. לשימוש אמיתי בטלפון מומלץ Starter. בכל שלב אפשר לשדרג מדף האתר ב-Render ("Settings" ← "Instance Type").
ה-PostgreSQL החינמי של Render נמחק אחרי כשלושים יום, ולכן משתמשים ב-Neon.

## שלב 1: מסד נתונים (Neon)

1. נכנסים ל-neon.tech ופותחים חשבון חינם.
2. יוצרים פרויקט חדש (Create project). אזור מומלץ: Frankfurt.
3. בעמוד הפרויקט לוחצים **Connect** ומעתיקים את ה-Connection string. היא נראית כך:
   `postgresql://user:password@host/dbname?sslmode=require`
4. שומרים אותה בצד. זה הערך של `DATABASE_URL`.

## שלב 2: הקוד (GitHub)

1. נכנסים ל-github.com ופותחים חשבון אם אין.
2. מפעילים **Fork** על ריפו הקוד שקיבלתם (או מעלים את הקבצים לריפו חדש). הריפו יכול להיות פרטי.

## שלב 3: האתר (Render)

1. נכנסים ל-render.com ופותחים חשבון. בוחרים **Connect GitHub** ומאשרים גישה לריפו.
2. לוחצים **New** ← **Blueprint**, בוחרים את הריפו. Render יזהה את `render.yaml`.
3. ממלאים את המשתנים:
   - `DATABASE_URL`: מה ששמרתם משלב 1.
   - `ADMIN_PASSWORD`: סיסמה חזקה לכניסה לאתר הניהול.
4. לוחצים **Apply** וממתינים כמה דקות עד שמופיע Live.
5. לשימוש אמיתי: בדף השירות ← **Settings** ← **Instance Type** ← Starter.
6. מעתיקים את כתובת האתר (למשל `https://school-attendance-xxxx.onrender.com`).

## שלב 4: כניסה והגדרה ראשונה

1. נכנסים לכתובת, לעמוד `/login/`. משתמש: `admin`, והסיסמה מהשלב הקודם.
2. **כיתות:** מוסיפים בעמוד כיתות.
3. **תלמידות:** ייבוא מאקסל (מורידים תבנית מהעמוד), או הוספה ידנית.
4. **הגדרות:** שם בית הספר, ימים שלא נספרים (ברירת מחדל שישי ושבת), איך מזהים את המתקשרת, וכד'.
5. **חופשות ומערכת שעות:** לפי הצורך.
6. **כללי התראה:** לפי הצורך. אפשר לבקש מהעוזר האישי לעזור.

## שלב 5: חיבור לשלוחה בימות המשיח

1. במערכת הטלפונית שלכם יוצרים שלוחה חדשה (למשל 7).
2. באתר: **הגדרות**. מזינים את תיקיית השלוחה (למשל `/7`), ושומרים.
3. בחלק "חיבור לשלוחה" מופיע קובץ ext.ini מוכן. מדביקים אותו בשלוחה, או מזינים מספר מערכת וסיסמה של ימות המשיח
   ולוחצים "הגדרה אוטומטית של השלוחה".
4. מחייגים לשלוחה ובודקים שיחה אחת מקצה לקצה: ת.ז. ← סוג ← אישור. ואז בודקים שהדיווח הופיע באתר בעמוד **דיווחים**.
5. בודקים גם איחור לשיעור, חיסור, ותלמידה לא מוכרת.

## שלב 6 (לא חובה): עוזר אישי

1. נכנסים ל-console.anthropic.com ויוצרים מפתח API (Create Key). נדרש כרטיס אשראי, והעלות לפי שימוש.
2. באתר: **הגדרות** ← "מפתח API של Claude" ← מדביקים ושומרים.
3. כפתור "💬 עוזר אישי" יעבוד בכל עמוד.

## אם משהו לא עובד

| תסמין | מה לעשות |
|---|---|
| "אין מענה משרת API" בטלפון | האתר נרדם (מסלול חינמי), או הכתובת בשלוחה שגויה. בדקו שהכתובת ב-`api_link` תואמת לזו שבהגדרות. |
| "לא מוגדר לינק" | חסר `api_link` ב-ext.ini של השלוחה. |
| הקלטת שמות לא נשמרת | תיקיית השלוחה (`phone_dir`) ריקה או שגויה בהגדרות. |
| צינתוק לא יוצא | בדקו מספר מערכת וסיסמה בהגדרות ולחצו "בדיקת חיבור". בדקו שיש יחידות בחשבון ימות המשיח. |
| שכחתי סיסמת מנהל | ב-Render מגדירים `RESET_ADMIN_PASSWORD=1` ו-`ADMIN_PASSWORD` חדשה, ומפעילים מחדש. אחר כך מסירים את `RESET_ADMIN_PASSWORD`. |
| צריך עזרה | בעמוד **עזרה** מפיקים קוד תמיכה זמני (צפייה בלבד) ושולחים למי שמסייע לכם. |

## גיבוי

בעמוד **גיבוי** מורידים את כל הנתונים. מומלץ לעשות זאת לפני מעבר שנה, ופעם בחודש.
